## 提交规范（Commit Conventions）

- **提交信息格式**：`<type>: <说明>`，type 取值：
  - `docs`：文档（Markdown / 会议纪要 / process 文件）
  - `feat`：新功能代码
  - `fix`：修复 bug
  - `test`：测试
  - `chore`：杂项
- **提交人**：使用个人 GitHub 账号提交。
- **提交方式**：成员直接提交到 `main`；重大变更经组内确认后提交 pull request。
- **版本标签**：每个里程碑交付物定稿后打 tag，如 `v1.0-m1`（详见 `../versions/changelog.md`）。
